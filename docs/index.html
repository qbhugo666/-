解决什么问题

SMA 等肢体障碍用户无法触屏操作手机，而「打不了字」与「点不了屏幕」之间，隔着一整个数字生活。与此同时，国产安卓阵营几乎没有任何厂商投入系统级的语音控制。

言出法随用「无障碍服务 + 离线语音识别」把操作权交还给声音：无需联网、无需专用硬件、无需电脑常伴——一部普通安卓手机，说话即可完成滑动、点击、输入等几乎全部操作。

核心能力

屏幕编号说「显示编号」，可点击元素全部标注数字；「点击 18」精准触达
屏幕网格十二宫格覆盖全屏，可逐级细化，任意位置都有编号
滑动与摇移四方向整页滚动；摇移小步微调，对准位置
双指缩放捏合放大 / 缩小，看图片看网页
语音听写说「输入」→ 说话 → 停顿后文字填入输入框（微信等）
文字编辑「删除」「光标左移 / 右移」「把 A 替换成 B」语音纠错
自定义指令用自己的说法绑定动作，语音录入零打字
个人词典人名地名加入词典后优先识别（如「黄信豪」）
设备控制音量（80% 安全上限）、静音、锁屏、通知中心、控制中心
全离线识别SenseVoice 引擎内置，无网络完整可用
识别灵敏度1~10 格滑块，适配轻声与含糊语音
深色模式跟随系统 / 浅色 / 深色三选项

你说 → 手机做

你说手机做
「显示编号」可点击元素全部标注数字
「点击 18」点击编号 18 对应的元素
「向上滑动」内容向上滚动一页
「输入」→「今天天气不错」文字填入输入框
「把不错替换成很好」输入框中的「不错」被替换为「很好」
「增加音量」音量加一格（80% 封顶，防失控）
「退出」结束会话，麦克风归还系统

完整指令表见仓库 README 与应用内「指令说明」。

安全设计

语音控制最怕两件事：麦克风失控、误触发连环执行。言出法随的安全机制是产品设计的一部分，不是补丁：

会话制占用即隔离、用完即归还；不长期持有麦克风
看门狗每段 3 分钟，最长 15 分钟，到点自动还麦
静音释放60 秒无语音自动归还麦克风
熔断保护短窗口内连续执行过多即判定误触发，立即停止
音量安全帽媒体音量 80% 封顶，杜绝误识别炸音量
静默自愈无障碍开关被系统撤销后，下次启动自动写回
